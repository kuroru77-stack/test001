# JLPT N3 학습 플랜: AI 음성 대화 + 아따맘마

> 대상: 지인 1명 (현재 수준 미확인, 아래 "확인 필요" 참조)
> 작성: 2026-10-05 · 첫 만남: 2026-10-07 (내일 모레)

---

## 0. 한 줄 요약

**"대화로 귀와 입을 열고, 시험 형식은 따로 채운다."**
AI 음성 대화와 아따맘마로 듣기·말하기는 빠르게 늘지만, 그것만으로 N3에 합격하기는 어렵습니다.
N3는 한자 읽기·문법 선택지·독해·청해 문제 형식을 묻는 시험이기 때문입니다.
그래서 비율을 **대화·영상 70% : 시험 대비 30%**로 시작하고, 시험 8주 전부터 **30 : 70**으로 뒤집습니다.

---

## 1. 이 방식의 진단

### 잘 맞는 점
- **입력(아따맘마) → 출력(Claude 대화)** 순환 구조가 생깁니다. 본 표현을 바로 말해 보면 기억에 오래 남습니다.
- 아따맘마(あたしンち)는 가족·학교·동네 이야기라 **N3 청해에 나오는 생활 장면**(가족 대화, 가게, 학교)과 겹칩니다.
- 혼자 음성 대화를 하면 사람 앞에서 틀릴까 봐 긴장할 일이 없습니다.

### 함정과 보완책

| 함정 | 왜 생기나 | 보완책 |
|---|---|---|
| AI가 너무 친절해서 틀려도 그냥 넘어감 | 기본 설정이 대화 흐름 유지 쪽 | 프로젝트 지시문에 "대화 끝에 틀린 문장 3개 교정"을 박아둠 (§6) |
| 음성 인식이 발음을 "알아서" 고쳐서 받아씀 | 음성→텍스트 변환이 추측함 | 대화 후 받아적힌 내 문장을 꼭 다시 읽어봄. 엉뚱하게 적혔다면 발음 문제 |
| 애니는 거의 반말(タメ口) | 가족끼리 대화 | 시험·실생활엔 です/ます체 필요 → Claude에게 "같은 말을 정중체로" 변환 연습 |
| 한자를 안 보게 됨 | 음성 위주 | 대화 후 텍스트 기록에서 한자 5개 골라 읽기 연습 |
| 시험 형식 경험 0 | 대화는 객관식이 아님 | 월 1회 모의 문제, 시험 8주 전부터 기출 집중 |

## 2. 세팅 (첫날 30분)

### 2-1. 모바일 일본어 자판
- **iPhone**: 설정 → 일반 → 키보드 → 키보드 → 새로운 키보드 추가 → 일본어 → **로마자(ローマ字)** 추천
  (영어 자판처럼 `ka` 치면 か. 한국인 입문자에게 가장 쉬움. 익숙해지면 かな 자판도 추가)
- **Android**: Gboard 설정 → 언어 → 키보드 추가 → 일본어 → 쿼티(QWERTY) 레이아웃
- 자판의 **마이크(받아쓰기) 버튼**도 일본어로 쓸 수 있음 → 음성 모드가 안 될 때 대체 수단

### 2-2. Claude 앱
1. Claude 모바일 앱 설치 · 로그인
2. **프로젝트 1개 생성**: 이름 `日本語 N3`
3. 프로젝트 지시문(instructions)에 §6-1 내용을 붙여넣기 → 매번 설명할 필요 없음
4. **음성 모드 테스트**: 일본어로 「こんにちは。今日はいい天気ですね。」라고 말해 보고, 일본어로 알아듣고 일본어로 답하는지 확인
   - 잘 안 되면: 일본어 자판 마이크로 말해서 **텍스트로 보내고**, 답변은 **읽어주기** 기능으로 듣기 (같은 효과)

## 3. D-2 미션: 아따맘마 1기 1~5화 × 3회

### 시간 계산
- 1화 약 22~24분 × 5화 × 3회 ≈ **약 6시간**
- 남은 시간: 오늘 밤 일부 + 내일 하루 + 모레 만남 전
- **현실적으로 빡빡함.** 그래서 "3번 똑같이 보기"가 아니라 **회차마다 목적을 다르게** 해서 부담을 줄입니다.

### 회차별 목적

| 회차 | 자막 | 목적 | 할 일 |
|---|---|---|---|
| 1회차 | 한국어 자막 (+일본어 음성) | 내용 이해 | 그냥 즐기기. 멈추지 않기 |
| 2회차 | 일본어 자막 (없으면 무자막) | 귀에 걸리는 말 잡기 | 들리는 단어·자주 나오는 말 메모. **에피소드당 3개** |
| 3회차 | 무자막 | 따라 말하기 | 메모한 장면에서 멈추고 **소리 내서 따라 하기**(섀도잉) |

> ⚠️ **중요**: 한국 방송판 아따맘마는 **한국어 더빙**입니다. 반드시 **일본어 원음**으로 봐야 합니다.

### 시간이 모자랄 때 (우선순위)
1. 1~2화는 무조건 3회
2. 3~5화는 1회차 + 3회차(따라 말하기)만
3. 그래도 모자라면 3~5화는 1회차만 → 만남 때 같이 봄

### 만남 때 가져올 것 (산출물)
- **표현 노트 10~15개**: 들린 말 그대로 (가나 표기 OK, 틀려도 OK)
- 가장 재미있었던 장면 1개 → 일본어로 한두 문장 설명 시도 (못 해도 OK)

### 아따맘마에서 자주 들릴 만한 표현 (예시 · 미리 알려주면 2회차가 쉬워짐)
| 표현 | 뜻 | 메모 |
|---|---|---|
| ただいま / おかえり | 다녀왔습니다 / 어서 와 | 가족 장면 필수 |
| いただきます / ごちそうさま | 잘 먹겠습니다 / 잘 먹었습니다 | 식사 장면 |
| ちょっと〜 | 잠깐, 좀 | 엄마가 자주 씀 |
| 〜じゃん | ~잖아 | 반말 |
| 〜てる / 〜ちゃった | ~하고 있어 / ~해 버렸어 | N4~N3 문법의 구어체 |
| なんで？ / どうして？ | 왜? | |
| うるさい | 시끄러워 | 남매 싸움 |

## 4. 만남 당일 세션 (90분)

| 시간 | 내용 | 방법 |
|---|---|---|
| 0~10분 | 수준 진단 | 히라가나·가타카나 읽기, 간단 자기소개 일본어로 |
| 10~30분 | 표현 노트 리뷰 | 지인이 적어온 표현을 같이 확인. 맞는 형태로 고치고 정중체 버전도 같이 |
| 30~50분 | 장면 재연 | 장면 1개 골라 역할 나눠 대사 따라 하기 |
| 50~75분 | **Claude 음성 대화 시연** | 지인 폰으로 직접. §6-2 프롬프트로 아따맘마 이야기를 일본어로. 내가 옆에서 막힐 때만 도움 |
| 75~90분 | 다음 2주 약속 | 아래 §5 Phase 1 루틴 합의 + 시험 목표일 결정 |

**당일 핵심 목표**: 지인이 "혼자서도 Claude랑 일본어로 10분 대화할 수 있겠다"는 느낌을 갖고 돌아가는 것.

## 5. 장기 커리큘럼

### 시험 일정
- JLPT는 매년 **7월 첫째 일요일**, **12월 첫째 일요일** 시행
- 2026년 12월 시험은 접수가 이미 끝났을 가능성이 높음 → **2027년 7월 시험 목표 권장** (약 9개월)
- 접수 기간·장소는 JLPT 한국 공식 사이트에서 확인 필요

### N3 시험 구성 (참고)
- 언어지식(문자·어휘) / 언어지식(문법)·독해 / 청해
- 합격: 종합 점수 기준 + **각 영역 최저 기준점**이 있음 → 한 영역만 잘해서는 불합격
- 일반적으로 어휘 약 3,700개, 한자 약 600~650자 수준으로 알려짐 (공식 목록은 없음)

### Phase 구성 (2027년 7월 기준)

| Phase | 기간 | 목표 | 대화·영상 : 시험대비 |
|---|---|---|---|
| **0. 입문 적응** | 10월 1~2주 | 아따맘마 + Claude 대화 습관 만들기 | 90 : 10 |
| **1. 기초 다지기** | 10월 3주 ~ 12월 | N4 문법 복습, 기본 한자 300자, 매일 대화 | 70 : 30 |
| **2. N3 본편** | 1월 ~ 4월 | N3 문법·어휘 정리, 한자 650자, 롤플레이 확장 | 60 : 40 |
| **3. 시험 형식 적응** | 5월 ~ 6월 중순 | 기출·모의고사, 시간 재고 풀기, 약점 보강 | 30 : 70 |
| **4. 마무리** | 시험 전 2주 | 틀린 문제 복습, 청해 집중, 컨디션 관리 | 20 : 80 |

### 주간 루틴 (Phase 1~2 기준, 하루 40~60분)

| 요일 | 내용 | 시간 |
|---|---|---|
| 월 | 아따맘마 1화 (2회차 방식) + 표현 3개 메모 | 30분 |
| 화 | Claude 음성 대화: 어제 본 화 이야기 | 15분 + 교정 확인 5분 |
| 수 | 문법 2개 학습 → Claude에게 그 문법으로 예문 만들어 달라 → 내가 따라 만들기 | 30분 |
| 목 | Claude 롤플레이 (가게·길 묻기·병원 등 상황) | 20분 |
| 금 | 한자 15~20자 + 단어 | 30분 |
| 토 | 아따맘마 1화 (3회차 섀도잉) | 30분 |
| 일 | **주간 점검**: Claude에게 이번 주 미니 테스트 10문항 요청 | 20분 |

### 체크포인트 (나와 만나는 날)
- 2주마다 1회 만남 권장: 표현 노트 + 10분 일본어 대화로 진척 확인
- 매달 말: Claude로 N3 형식 미니 모의 20문항 → 정답률 기록

| 월말 점검 | 목표 정답률 |
|---|---|
| 12월 | 40% |
| 2월 | 55% |
| 4월 | 65% |
| 6월 | 75% 이상 |

## 6. Claude 프롬프트 템플릿

### 6-1. 프로젝트 지시문 (한 번만 붙여넣기)

```
あなたは私の日本語の会話パートナーです。私はJLPT N3合格を目指している韓国人です。

ルール:
1. N3レベルの語彙と文法で話してください。難しい言葉を使ったら、すぐに簡単な言葉で言い換えてください。
2. 一回の返事は短く(2〜3文)。最後に必ず私に質問をしてください。
3. 会話中は流れを止めないでください。私が「おわり」と言ったら、今日の会話で私が間違えた文を3つ選んで、
   「私の文 → 正しい文 → 韓国語で短い説明」の形で教えてください。
4. 私が韓国語で話したら、それを日本語でどう言うか教えて、もう一度言わせてください。
5. 毎回、今日の会話で使ったN3の文法を1つ紹介してください。
```

(한국어 뜻: N3 수준으로 말하기 · 짧게 답하고 질문으로 끝내기 · 대화 중엔 끊지 말고 "おわり"라고 하면 틀린 문장 3개 교정 · 한국어로 말하면 일본어 표현 알려주고 다시 말하게 하기 · 매번 N3 문법 1개 소개)

### 6-2. 아따맘마 복습 대화
```
今日は『あたしンち』の第○話を見ました。その話について日本語で話したいです。
私が内容を説明するので、質問をしてください。
```

### 6-3. 반말 → 정중체 변환 연습
```
アニメで聞いた表現を言います。丁寧な言い方(です・ます)に直して、使い分けを教えてください。
```

### 6-4. 상황 롤플레이
```
ロールプレイをしましょう。場面は「コンビニ」です。あなたは店員、私はお客さんです。始めてください。
```
(장면 바꾸기: 駅で道を聞く / レストランで注文する / 病院の受付 / 友達と週末の予定を決める)

### 6-5. 주간 미니 테스트
```
JLPT N3の形式で、文法5問と語彙5問の4択問題を出してください。答えは私が全部答えた後に見せてください。
```
